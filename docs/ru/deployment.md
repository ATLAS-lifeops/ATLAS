# Режимы развертывания

ATLAS поддерживает два режима через `ATLAS_DEPLOYMENT_MODE`:

- `self_hosted`: режим по умолчанию. Локальная настройка может быть включена, токен Telegram-бота задает владелец установки.
- `hosted`: основа серверного режима. Setup должен быть выключен, Telegram работает через webhook, токены берутся только из окружения или секретов сервера.

Hosted mode блокирует небезопасные сочетания: публичный setup, отсутствие webhook URL, отсутствие токена или polling-only запуск.

Статусы могут показывать режим, состояние setup и наличие настроек. Telegram token, webhook secret и LLM API key не отображаются.
