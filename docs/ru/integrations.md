# Интеграции

Основа интеграций построена через порты:

- настройки интеграций хранят только безопасные metadata через `IntegrationSettingsPort`;
- Markdown export работает в рамках пользователя;
- calendar integration содержит preview-контракт без OAuth и внешней синхронизации;
- панель настроек Telegram ведёт в статус интеграций.

Будущие интеграции могут реализовать эти порты без разделения ATLAS на микросервисы.
