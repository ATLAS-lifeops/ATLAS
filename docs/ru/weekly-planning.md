# Недельное планирование

Недельное планирование хранит один фокус недели для пользователя и недели. Неделя начинается в понедельник.

Команда `/week <главный фокус>` сохраняет или обновляет текущий недельный фокус. Команда `/week` без аргумента показывает текущий фокус.

Недельный отчёт использует сохранённый фокус, если он есть. Модель намеренно компактная и не добавляет внешнюю календарную синхронизацию.
