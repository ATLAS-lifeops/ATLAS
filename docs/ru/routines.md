# Рутины

Настройки рутин хранят:

- время дневного check-in;
- время вечерней рефлексии;
- timezone;
- quiet hours;
- флаг включения.

Scheduler проверяет quiet hours и использует per-user/per-day ключ напоминания, чтобы не отправлять дубликаты одного типа напоминания за день.

Панель настроек Telegram ведёт в раздел routines и показывает текущие сохранённые настройки.
