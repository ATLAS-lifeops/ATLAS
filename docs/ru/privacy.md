# Приватность

ATLAS добавляет основы пользовательского контроля данных:

- `/privacy`: описание сохраненных профиля, check-ins, привычек, рефлексий, отчетов, памяти и Telegram-идентификаторов;
- `/memory`: категории и счетчики памяти без сырого чувствительного содержания по умолчанию;
- `/export`: пользовательский JSON и Markdown export;
- `/forget`: архивирование памяти после подтверждения;
- `/delete_my_data`: удаление пользовательских данных после строгого подтверждения.

Разрушающие операции требуют значение `DELETE` на уровне сервиса. Export, forget и deletion всегда используют внутренний user id и не затрагивают других пользователей.
