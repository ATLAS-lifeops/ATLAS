# Отчёты

Отчёты используют детерминированные данные:

- тренды энергии, фокуса, стресса и сна;
- регулярность привычек;
- сохранённый недельный фокус;
- архив сгенерированных отчётов.

Trend detection использует только сохранённые check-ins и привычки. Отчёты показывают отсутствие данных вместо выдуманных выводов.
